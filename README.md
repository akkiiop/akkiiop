### Key Capabilities & Engineering Highlights:
* **Multi-Filter Search**: Queries the GitHub REST API with keyword, programming language, sort (`stars`, `forks`, `updated`), and order filters.
* **Trending Discovery**: Approximates trending repositories across customizable time windows (`day`, `week`, `month`, `year`) and minimum star thresholds.
* **Side-by-Side Comparison**: Compares two repositories simultaneously with automated numerical delta calculations for stars, forks, and open issues.
* **Star Velocity Tracking**: Captures timestamped repository snapshots persisted in MySQL to monitor star growth velocity over time.
* **Favorites Management**: Local repository bookmarking subsystem with duplicate check validations.
* **Clean Terminal UX**: Dynamic width alignment, word-wrapped descriptions, aligned colons, and thousands separators (`%,d`) without third-party styling bloat.
* **Tech Stack**: `Java 21` • `Spring Boot` • `Picocli` • `Spring RestClient` • `MySQL` • `Spring Data JPA` • `JUnit 5` • `Mockito`
